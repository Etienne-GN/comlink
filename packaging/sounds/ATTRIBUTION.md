# Bundled sounds

These files were supplied by the operator as royalty-free audio for use
in Comlink. They were converted from the MP3 masters in `ringtones/`
to 16 kHz mono 16-bit PCM WAV by `ringtones/regenerate.sh`, because
pjmedia's file player reads WAV only.
